# MyWork - 产品概述

## 产品简介

**MyWork** 是一款轻量级的桌面应用程序，专为需要高效记录日常工作、管理任务并生成专业工作报告的用户设计。

通过简洁的界面设计和强大的功能组合，MyWork 帮助用户：
- 快速记录每日工作内容
- 使用看板方式高效管理任务
- 借助 AI 自动生成结构化工作报告
- 通过数据统计直观了解工作状态

## 产品定位

### 目标用户
- **产品经理** - 需要记录日常工作并生成周报/月报
- **研发工程师** - 管理开发任务，记录技术工作
- **项目经理** - 追踪项目进度，汇总团队工作
- **自由职业者** - 记录工作内容，便于向客户汇报
- **任何需要管理日常工作的人**

### 核心价值
1. **简单高效** - 无需复杂配置，上手即用
2. **本地优先** - 数据存储在本地，保护隐私
3. **AI 赋能** - 自动化报告生成，节省时间
4. **美观实用** - 现代化界面设计，舒适使用体验

## 产品版本

当前版本：**0.1.3**

## 技术栈

- **Electron** - 跨平台桌面应用框架
- **React 18** - 前端 UI 框架
- **TypeScript** - 类型安全的 JavaScript
- **Vite** - 快速构建工具
- **SQLite** - 本地数据存储
- **Zustand** - 轻量级状态管理
- **Tailwind CSS** - 原子化 CSS 框架
- **@dnd-kit** - 现代化拖拽库

## 平台支持

- **Windows** (x64)
- **macOS** (Intel + Apple Silicon)
- **Linux** (AppImage)

## 设计理念

### 简洁至上
我们相信好的工具应该简单直观。MyWork 的每一个功能都经过精心设计，确保用户能够专注于工作本身，而不是工具的使用。

### 隐私优先
所有数据存储在用户本地设备上，不经过云端，不收集用户数据。API Key 通过系统安全存储加密保存。

### 效率优先
提供全局快捷键、快速记录窗口等功能，让用户能够在不切换当前工作的情况下快速记录想法和任务。
