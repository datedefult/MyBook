## 快速开始

### 安装与启动

#### 下载安装
1. 从官方网站下载对应平台的安装包
2. Windows：运行 `.exe` 安装程序
3. macOS：打开 `.dmg` 镜像，拖拽到 Applications
4. Linux：运行 AppImage 直接执行

#### 首次启动
1. 启动应用后，你会看到**工作日志**页面
2. 可以直接开始记录你的第一条工作日志

### 界面概览

#### 顶部导航栏
- **工作日志**：记录和查看日志
- **看板**：管理任务
- **报告**：生成 AI 报告
- **统计**：查看数据统计
- **设置**：个性化配置

## 工作日志

### 记录第一条日志

#### 步骤
1. 在顶部的输入框中输入内容，例如：`完成了用户登录页面的开发 #前端`
2. 按 `Enter` 键保存
3. 日志会立即出现在下方列表中

#### 输入技巧
- 使用 `#标签名` 可以自动添加标签
- 例如：`修复了登录 bug #后端 #紧急` 会自动添加两个标签

### 添加标签的多种方式

#### 方式一：输入时自动识别
输入内容时直接包含 `#标签名`，如：
```
完成 API 接口开发 #后端 #API
```
#### 方式二：使用标签选择器
1. 点击输入框下方的标签区域
2. 点击已有标签选择
3. 或输入新标签名创建

#### 方式三：编辑已有日志的标签
点击日志卡片上的标签区域可编辑标签

### 添加备注

#### 何时使用备注
备注用于记录更详细的信息，不会显示在日志内容下方。

#### 步骤
1. 点击输入框下方的 `+ 备注` 按钮
2. 在展开的备注框中输入详细内容
3. 保存日志时会同时保存备注

### 使用 AI 优化日志

#### 前置条件
需要先在设置中配置好 AI 服务（详见 [设置配置](#设置配置)）。

#### 优化步骤
1. 输入日志内容后
2. 点击输入框旁的 `AI` 按钮
3. 等待 AI 优化完成
4. 选择替换或保留原样

#### 自动替换设置
在设置中可开启"默认自动替换"，开启后优化结果直接替换输入内容。

### 搜索日志

#### 关键词搜索
1. 在搜索框中输入关键词
2. 实时显示匹配结果
3. 支持搜索内容、标签等

#### 清除搜索
点击搜索框右侧的 `×` 按钮清除搜索。

### 筛选日志

#### 展开筛选面板
点击左侧的筛选按钮（图标为 `>`，展开筛选面板。

#### 按日期筛选
- 点击日历上的日期筛选单日
- 或选择"今日"、"本周"快速筛选
- 或设置自定义日期范围

#### 按标签筛选
在筛选面板下方点击标签，只显示该标签下的日志。

#### 清除筛选
点击"全部记录"或"清除筛选"按钮。

### 管理日志

#### 删除日志
1. 鼠标悬停在日志卡片上
2. 点击出现的删除图标
3. 10 秒内可点击撤销

#### 撤销删除
删除后会出现撤销提示，10 秒内点击可恢复。

#### 复制日志内容
点击日志卡片旁的复制按钮可复制内容。

### 导出日志

#### 导出步骤
1. 点击右上角的导出按钮
2. 选择导出格式：
   - CSV：适合 Excel 打开
   - Markdown：适合文档编辑
3. 选择保存位置

#### 筛选导出
先筛选出想要的日志，再点击导出，只会导出筛选结果。

### 展开/折叠日期分组

#### 单个分组
点击日期标题左侧的箭头可展开/折叠该日期的日志。

#### 全部展开/折叠
点击顶部工具栏的"展开全部"或"折叠全部"按钮。

## 看板任务

### 添加任务

#### 快速添加
1. 在看板顶部输入框输入任务标题
2. 按 `Enter` 保存
3. 任务自动添加到"待办"列

#### 添加详细信息
1. 输入标题后，点击展开描述输入框
2. 可添加描述和标签
3. 点击"添加"按钮

### 编辑任务

#### 方式一：双击编辑
双击任务卡片进入编辑模式。

#### 方式二：点击编辑按钮
鼠标悬停显示编辑按钮，点击进入编辑。

#### 编辑内容
- 修改标题
- 修改描述
- 修改标签
- 设置截止日期
- 按 `Ctrl+Enter` (Windows)` 保存
- 按 `Esc` 取消

### 拖拽任务

#### 在列内排序
按住任务卡片，上下拖拽调整顺序。

#### 变更状态
拖拽到其他列变更状态：
- 待办 → 进行中：开始处理
- 进行中 → 已完成：完成任务

### 完成任务

#### 方式一：拖拽到完成列
1. 拖拽任务到"已完成"列
2. 会弹出确认框确认生成工作日志
3. 可编辑日志内容
4. 确认后任务标记完成并生成日志

#### 方式二：状态选择器
1. 在任务卡片上选择"已完成"

#### 标签携带
任务标签会自动添加到生成的日志中。

### 设置截止日期

#### 设置步骤
1. 点击任务卡片上的截止日期
2. 或编辑任务时设置
3. 选择日期
4. 截止日期会显示在卡片上

#### 截止提醒
- 剩余 2 天内：琥珀色显示
- 已过期：红色显示

### 使用草稿箱

#### 打开草稿箱
点击右侧的草稿箱图标展开。

#### 添加草稿
1. 在草稿箱输入框输入
2. 按回车保存

#### 移动到看板
拖拽草稿到看板列开始处理。

### 展开更多任务

每列默认显示 5 条任务，点击"显示更多"展开查看全部。

### 删除任务

点击任务卡片上的删除图标删除任务（不可恢复）。

## AI 报告

### 配置 AI 服务

#### 首次配置
1. 点击右上角设置图标
2. 进入"AI 配置"区域
3. 选择提供商：OpenAI 或 Anthropic
4. 输入 API Key
5. 配置 Base URL（如使用第三方服务）
6. 输入模型名称
7. 保存配置

#### 获取 API Key
- OpenAI：访问 [platform.openai.com](https://platform.openai.com)
- Anthropic：访问 [console.anthropic.com](https://console.anthropic.com)

### 生成报告

#### 步骤
1. 切换到"报告"页面
2. 选择时间范围：
   - 今日
   - 本周
   - 本月
   - 本季度
   - 自定义
3. 点击"生成报告"
4. 等待 AI 生成
5. 查看报告

#### 报告选项
- **语言：选择报告语言
- **风格**：简洁/详细/轻松

### 编辑报告

#### 编辑模式
生成报告后可直接编辑内容，支持 Markdown 格式。

#### 实时预览
编辑时可实时查看预览效果。

### 保存报告

满意的报告可保存到历史记录，方便以后查看。

### 导出报告

#### 导出方式
- **复制**：一键复制到剪贴板
- **导出 Markdown**：保存为 .md 文件
- **导出文本**：保存为 .txt 文件

### 自定义报告模板

#### 自定义系统提示词
在设置中可自定义 AI 的系统提示词，定义报告风格和要求。

#### 自定义报告模板
在设置中可自定义报告的输出格式模板。

## 数据统计

### 查看统计概览

切换到"统计"页面，顶部显示四个统计卡片：

- **连续记录天数**：坚持记录的连续天数

- 每周完成任务趋势
- 查看工作节奏

## 快速记录

### 使用全局快捷键

#### 默认快捷键
- **记录日志**：`Ctrl+Shift+L` (Windows/Linux) / `Cmd+Shift+L` (macOS)
- **添加任务**：`Ctrl+Shift+T` (Windows/Linux) / `Cmd+Shift+T` (macOS)

#### 唤出窗口
按下快捷键会弹出快速记录窗口。

### 快速记录日志

1. 按下日志快捷键
2. 输入内容
3. 可选择标签
4. 按回车保存
5. 窗口自动关闭

### 快速添加任务

1. 按下任务快捷键
2. 输入任务标题
3. 可选择标签
4. 按回车保存

### 自定义快捷键

在设置 → 快捷键设置中可自定义全局快捷键。

## 常见问题

### 数据相关

#### Q: 数据存储在哪里？
A: 数据存储在本地 SQLite 数据库中：
- Windows: `%APPDATA%/MyWork/`
- macOS: `~/Library/Application Support/MyWork/`
- Linux: `~/.config/MyWork/`

#### Q: 会自动备份吗？
A: 是的，每日自动备份到 `backups/` 目录。

#### Q: 如何迁移数据到新设备？
A: 复制整个数据目录到新设备即可。

### AI 相关

#### Q: AI 功能需要付费吗？
A: 应用本身免费，但使用 AI API 需要付费（OpenAI 或 Anthropic 收费）。

#### Q: 我的 API Key 安全吗？
A: 安全，使用系统加密存储，不上传任何地方。

#### Q: 报告生成失败怎么办？
A: 检查：
1. API Key 是否正确
2. 网络连接是否正常
3. Base URL 是否正确
4. 账户是否有余额

#### Q: 可以使用国内的 AI 服务吗？
A: 可以，只要兼容 OpenAI API 格式，配置自定义 Base URL 即可。

### 功能相关

#### Q: 删除的日志能恢复吗？
A: 删除后 10 秒内可撤销，超过后无法恢复。

#### Q: 删除的任务能恢复吗？
A: 任务删除后无法恢复，请谨慎操作。

#### Q: 标签颜色可以自定义吗？
A: 当前版本自动分配颜色，暂不支持自定义。

#### Q: 支持数据同步吗？
A: 当前版本只支持本地存储，暂不支持云端同步。

### 使用相关

#### Q: 如何反馈问题或建议？
A: 欢迎通过 GitHub Issues 反馈。

#### Q: 应用会收集我的数据吗？
A: 不会，所有数据本地存储，不收集任何数据。

## 提示与技巧

### 高效使用建议

1. **养成习惯**：每天记录，保持连续记录
2. **善用标签**：用标签分类不同项目和优先级
3. **定期回顾**：每周查看统计和生成报告
4. **使用快捷键**：熟练使用快捷键提高效率
5. **及时备份**：定期备份数据

### 标签使用建议

- 按项目分类：`#项目A`、`#项目B`
- 按类型分类：`#开发`、`#会议`、`#文档`
- 按优先级：`#紧急`、`#重要`
- 组合使用：一条记录可加多个标签

### 看板使用建议

- **待办**：放接下来要做的
- **进行中**：放正在做的
- **已完成**：自动记录成就
- **草稿箱**：放想法和以后再看
